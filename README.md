# AI 因果律 · 平行人生生成器

> 每个人都有后悔的事。输入它，让 AI 帮你看看另一种可能。
>
> 输入你真实发生过的遗憾 → AI 推演一条「如果当时做了不同选择」的平行人生（因果链 + 人生节点 + 金句）→ **MiniMax 绘出平行世界配图** → 一键生成「我的平行人生」分享卡，社交裂变。

## 一、这是什么 / 为什么做

「如果我昨天买了那只股票」「如果我当时说了那句话」——人总被困在"如果当初"里。

**AI 因果律** 把这种情绪做成了一个可玩的玩具：你给它一段真实遗憾和一个不同的选择，它用大模型推演出一条完整的平行人生，再用 **MiniMax image-01** 把那个平行世界画出来。最终产出一张可以发朋友圈/小红书的「我的平行人生」分享卡。

**传播力**：用户会自发分享"我的平行人生"，自带社交裂变属性。

---

## 二、和 MiroFish 的区别（我们占了哪格）

MiroFish（[666ghj/MiroFish](https://github.com/666ghj/MiroFish)，⭐~34k）是**企业级多智能体推演引擎**：上传报告 → 构建百万级 Agent 平行世界 → 推演未来，常规模拟 **$5/次**，需 Python+Node+Docker，AGPL-3.0。

我们刻意不做它的重型架构，而是占了它完全没覆盖的一格：

| 维度 | MiroFish | **AI 因果律** |
|---|---|---|
| 锚点 | 宏观新闻/报告/政策 | **你的真实遗憾**（个人情感） |
| 视角 | 企业决策沙盘 | **个人因果链 + 情感叙事** |
| 配图 | 无 | **MiniMax image-01 生成平行世界视觉** |
| 体感 | 重部署、贵 | **单页即玩**，无需全家桶 |
| 传播 | 社区画廊 | **可分享的"平行人生"卡片**，裂变 |

> 完整竞品解析（含 11 个同类项目）见 [`docs/COMPETITIVE_ANALYSIS.md`](docs/COMPETITIVE_ANALYSIS.md)。
> 一句话：**MiroFish 是给 CEO 用的"未来沙盘"，AI 因果律 是给普通人用的"后悔药 + 朋友圈爆款生成器"。**

我们借鉴了 MiroFish demo 的**交互骨架**——现实种子 → 平行变量 → 推演工作台 → 报告——但把它从"企业预测"平移成了"个人平行人生"。

## 三、功能

- 🌌 **因果律推演**：基于真实遗憾 + 一个不同选择，生成结构化平行人生（世界标题 / 因果链 / 人生节点 / 结局 / 金句）。
- 🖼️ **MiniMax 出图**：自动用 image-01 把平行世界绘成电影感画面（应用核心分享件）。
- 🃏 **分享卡**：一键把"配图 + 金句 + 标题"合成 PNG 下载，直接发社交平台。
- 📋 **复制文案**：一键复制带话题标签的分享文案。
- ⚡ **Demo 模式**：未配置 Key 也能立即体验完整交互（返回内置示例），保证"打开就能玩"。
- 🎯 **一键示例**：内置"那只涨停股 / 没说出口的话 / 那个志愿"三个预设，点一下即推演。

## 四、快速开始

```bash
git clone https://github.com/你的用户名/ai-causality-lab.git
cd ai-causality-lab
npm install
cp .env.example .env
# 编辑 .env，填入 MINIMAX_API_KEY（在 https://www.minimax.io/ 获取）
# 文本模型默认 MiniMax-M3，出图默认 image-01
npm start
# 打开 http://localhost:3000
```

> 不填 Key 也能跑：会自动进入 **Demo 模式**（返回内置示例叙事），方便先看效果与交互。

## 五、架构与流程

```
┌─────────────┐    POST /api/causality    ┌──────────────────┐
│  前端控制台  │ ───────────────────────▶ │   Node 后端代理    │
│ (public/)   │                          │   server.js      │
│ 原事件+变量  │ ◀────── 叙事 JSON ────── │                  │
│ 进度动画     │                          │ ① MiniMax-M3     │
│ 分享卡 canvas│ ◀────── 配图(url/b64) ── │    (chat 结构化)  │
└─────────────┘                          │ ② MiniMax image-01│
                                         └──────────────────┘
```

**推演四步**（平移 MiroFish 骨架，个人化改造）：
1. **现实种子**：读取你的真实遗憾
2. **平行变量**：注入"如果当时…"的分叉选择
3. **因果链生成**：推演蝴蝶效应，产出结构化平行人生
4. **世界渲染**：MiniMax 绘出平行世界画面

后端通过 OpenAI 兼容接口调用 MiniMax，**API Key 仅存于服务端 `.env`，不暴露给浏览器**。

## 七、部署

- **本地 / 自建**：`npm start`，反向代理到 3000 端口即可。
- **Render / Railway / 云函数**：连环境变量 `MINIMAX_API_KEY` 等，启动命令 `npm start`。
- **纯静态前端（无后端）**：如需纯前端部署，可改为浏览器直连 MiniMax（自行承担 Key 暴露风险），本项目默认走后端代理更安全。
