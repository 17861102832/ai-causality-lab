# AI 因果律 · 平行人生生成器

> 每个人都有后悔的事。输入它，让 AI 帮你看看另一种可能。
>
> 输入你真实发生过的遗憾 → AI 推演一条「如果当时做了不同选择」的平行人生（因果链 + 人生节点 + 金句）→ **MiniMax 绘出平行世界配图** → 一键生成「我的平行人生」分享卡。

## 一、这是什么 / 为什么做

「如果我昨天买了那只股票」「如果我当时说了那句话」——人总被困在“如果当初”里。

**AI 因果律** 把这种情绪做成了一个可玩的玩具：你给它一段真实遗憾和一个不同的选择，它用大模型推演出一条完整的平行人生，再用 **MiniMax image-01** 把那个平行世界画出来。最终产出一张可以发朋友圈/小红书的「我的平行人生」分享卡。

**传播力**：用户会自发分享“我的平行人生”，自带社交裂变属性。

---

## 二、定位：个人情感向的平行人生模拟器

现有的 what-if 工具多聚焦宏观历史、企业预测或开放式文字冒险。**AI 因果律** 占的是另一格：

| 维度 | 市面上多数工具 | **AI 因果律** |
|---|---|---|
| 锚点 | 历史/世界/虚构 | **你的真实遗憾**（“昨天没买那只股”“三年前没表白”） |
| 视角 | 宏观推演 | **个人情感 + 因果链**（一个选择如何改写时间线） |
| 配图 | 多数无 | **MiniMax image-01 生成平行世界视觉**，分享核心 |
| 体感 | 重部署/贵 | **单页即玩**，无需复杂环境 |
| 传播 | 社区画廊/纯文本 | **“我的平行人生”分享卡**，直接下载发社交平台 |

一句话：**给每个普通人玩的“后悔药 + 朋友圈爆款生成器”。**

## 三、功能

- 🌌 **因果律推演（多节点递归引擎）**：种子节点拆维度 → 多维度节点并行预测第一阶因果 → 递归深化节点按层迭代（推理→再推理→再推理）→ 合成节点提炼统一结论。
- 🖼️ **MiniMax 出图**：自动用 image-01 把平行世界绘成电影感画面（应用核心分享件）。
- 🃏 **分享卡**：一键把“配图 + 金句 + 标题”合成 PNG 下载，直接发社交平台。
- 📋 **复制文案**：一键复制带话题标签的分享文案。
- ⚡ **Demo 模式**：未配置 Key 也能立即体验完整交互（返回内置示例，且完整展示多节点递归结构），保证“打开就能玩”。
- 🎯 **强度档位**：轻量 / 标准 / 深度，控制节点数与递归深度。
- 🎯 **一键示例**：内置“那只涨停股 / 没说出口的话 / 那个志愿”三个预设，点一下即推演。

## 四、快速开始

```bash
# 1. 克隆
git clone https://github.com/你的用户名/ai-causality-lab.git
cd ai-causality-lab

# 2. 装依赖
npm install

# 3. 配置 MiniMax Key（想要真实专属推演 + 配图时必须）
cp .env.example .env
# 编辑 .env，填入 MINIMAX_API_KEY（在 https://www.minimax.io/ 获取）
# 文本模型默认 MiniMax-M3，出图默认 image-01

# 4. 启动
npm start
# 打开 http://localhost:3000
```

> 不填 Key 也能跑：会自动进入 **Demo 模式**（返回内置示例叙事，并完整展示多节点递归结构），方便先看效果与交互。

## 五、架构：多节点递归推理引擎

```
┌─────────────┐    POST /api/causality    ┌──────────────────────┐
│  前端控制台  │ ───────────────────────▶ │   Node 后端代理        │
│ (public/)   │                          │   server.js          │
│ 原事件+变量  │ ◀────── 叙事 JSON ────── │                      │
│ 进度动画     │                          │ ① 种子节点(拆维度)    │
│ 分享卡 canvas│ ◀────── 配图(url/b64) ── │ ② 推演节点×W(并行预测) │
└─────────────┘                          │ ③ 递归深化×D(推理再推理)│
                                         │ ④ 合成节点(统一结论)  │
                                         │ ⑤ MiniMax image-01   │
                                         └──────────────────────┘
```

**引擎五步**：
1. **种子节点**：读取真实遗憾，定位分叉点，拆出 N 个人生维度。
2. **并行推演节点 ×W**：各维度并行预测第一阶因果链（多节点预测）。
3. **递归深化节点 ×(W×D)**：每个维度按层迭代深挖“更深一阶、几年后才显形”的后果（推理→再推理→再推理）。
4. **合成节点**：汇总各维度链，提炼统一因果链 + 金句 + 出图提示。
5. **出图节点**：MiniMax image-01 绘出平行世界画面。

后端通过 OpenAI 兼容接口调用 MiniMax，**API Key 仅存于服务端 `.env`，不暴露给浏览器**。

## 七、部署

- **本地 / 自建**：`npm start`，反向代理到 3000 端口即可。
- **Render / Railway / 云函数**：连环境变量 `MINIMAX_API_KEY` 等，启动命令 `npm start`。
- **纯静态前端（无后端）**：如需纯前端部署，可改为浏览器直连 MiniMax（自行承担 Key 暴露风险），本项目默认走后端代理更安全。
