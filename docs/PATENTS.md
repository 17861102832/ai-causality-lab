## 专利一 · 遗憾锚定因果链生成方法（Regret-Anchored Causal Chain）

- **技术领域**：生成式 AI、个人化叙事推演。
- **背景技术**：现有 what-if 推演多以宏观历史、企业预测或开放文本冒险为起点，与个体真实生命经验脱节，产出难以引发情感共振。
- **发明内容**：以用户输入的**真实发生过的遗憾**作为唯一不可违背的锚点，约束多节点推演全程围绕“这一个具体的人”展开；系统拒绝宏大叙事，强制把分叉点、因果链、人生节点收敛到用户可代入的生活细节。
- **差异化**：把“个人真实遗憾”作为硬约束锚，而非可选输入——这是与通用推演引擎在**问题定义层**的根本分野。

## 专利二 · 多节点并行预测 + 递归深化的双层推演架构（Multi-Node Parallel Prediction with Recursive Deepening）

- **技术领域**：多智能体编排、递归推理。
- **背景技术**：单轮大模型调用只能产出一层结果，无法体现“蝴蝶效应”随时间的层层展开，深度与可信度受限。
- **发明内容**：
  1. **种子节点**定位分叉点并拆出 N 个人生维度；
  2. **推演节点 × N** 并行预测各维度第一阶因果链（多节点预测）；
  3. **递归深化节点 × (N × D)** 按层迭代，每一层在上一层基础上推演“更深一阶、几年后才显形的后果”（推理 → 再推理 → 再推理）；
  4. **合成节点**汇总成统一结论。
- **差异化**：维度并行 × 递归迭代的**显式双层结构**，而非黑盒单调用；推理深度（D）与宽度（N）可配置，强度可量化。

## 专利三 · 跨维度蝴蝶效应回响机制（Cross-Dimensional Butterfly Echo）

- **技术领域**：多智能体协同、因果图收敛。
- **背景技术**：多数多节点系统各节点独立产出、互不干涉，丢失了“事业变化影响关系、关系变化反噬心智”的真实人生耦合。
- **发明内容**：在递归深化与合成阶段，允许一个维度的后果**回响**到另一维度（如事业跃迁改变情感关系张力），由合成节点做跨维度收敛，输出一条内部自洽、彼此牵连的统一因果链。
- **差异化**：把“维度耦合”作为一等公民显式建模，而非事后拼接。

## 专利四 · 情绪金句与视觉提示联合蒸馏（Emotion-GoldenLine & Visual-Prompt Joint Distillation）

- **技术领域**：可控生成、社交分享闭环。
- **背景技术**：推演结果多为长文本，缺乏可直接传播的“记忆锚点”与配套视觉，裂变效率低。
- **发明内容**：合成节点在产出统一因果链的同时，**联合蒸馏**两条短输出——① 一句 ≤20 字、情绪极致的“金句”（分享卡记忆锚）；② 一段中文电影感“视觉提示”直接喂给出图模型。二者与叙事同源生成，形成“叙事 → 金句 → 图像 → 分享卡”的一体化闭环。
- **差异化**：把“可分享性”作为生成目标之一内建于引擎，而非外挂后处理。

## 专利五 · 本地优先 + 零参与的情感推演隐私架构（Local-First Zero-Participation Privacy）

- **技术领域**：隐私计算、本地优先 AI。
- **背景技术**：个人遗憾属高敏数据；云端记忆/推演系统存在隐私暴露与数据出域风险。
- **发明内容**：① API Key 仅存于服务端 `.env`，绝不暴露浏览器；② 用户遗憾数据不出本机（本地优先）；③ 无 Key 时自动进入 Demo 模式，开箱即玩、零配置零参与。
- **差异化**：在“个人高敏情感数据”场景，把隐私与零门槛作为架构默认值，区别于依赖云端账户的推演产品。

### 差异化总览（相对通用多智能体推演引擎）

| 维度 | 通用推演引擎 | AI 因果律 |
|---|---|---|
| 起点 | 任意/宏观 | **真实遗憾锚定**（硬约束） |
| 结构 | 单轮或松散多 agent | **维度并行 × 递归深化**双层 |
| 维度关系 | 各自独立 | **跨维度回响**耦合 |
| 产出 | 长文本 | **金句 + 视觉提示**联合蒸馏 |
| 数据 | 常依赖云端 | **本地优先 + 零参与** |

> 守住这五格，即是我们在该赛道不可替代的护城河。
