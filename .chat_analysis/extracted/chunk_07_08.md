## 一、技术知识点（工具/平台/模型/功能/原理等）

1. **[2026-04-13 06:20] 金杰**：手部关键点连线（手线/骨骼连线可视化）实现方案。Unity 最常用：插件 LightBuzz Hand Tracking（支持 21/22 个关键点）、MediaPipe Unity（谷歌官方）；添加 HandTracking + HandVisual 组件，用 LineRenderer 画骨骼连线，核心命令 `HandVisual.Toggle(true)`（Inspector 勾选 Is Visible）。Unreal：Hand & Finger Tracker（基于 MediaPipe）、Meta Quest Hand Tracking 官方插件，启用 Hand Component，打开 Hand Outline 或 Bone Link 可视化，蓝图节点 `Enable Hand Tracking`。Snap AR：HandVisual + ObjectTracking3D，命令 `addAttachmentPoint`（把指尖/关节绑定到场景对象）。iOS 录屏显示触摸线：插件 Touch-Viz，控制中心一键开关。**适用场景**：手势识别类游戏/交互，做「手线可视」调试的第一步。

## 二、实用技巧与提示词方法（含原文提示词）

1. **[2026-04-13 06:13] 金杰**：做手势游戏的第一步——「把手线先亮出来，这是第一步，这样玩才第一步都没到，你可以跟 AI 说下」。

   > 直接输入「我要个ZIP包，8M内，index目录下」

3. **[2026-04-17 08:48] 耿家威**（转发官方内测指南）中给出的抖音互动空间**通用 Prompt 模板**（应与智能体对话时改写，避免需求遗漏）：
   - 角色定位：指定为资深 HTML5 Canvas 开发者，精通移动端适配与性能优化；
   - 核心目标：开发纯离线的 HTML5 互动作品；
   - 玩法细节：明确作品名称、玩法规则、交互方式、美术风格；
   - 强制约束：严格遵守离线运行、无网络请求、体积限制、适配要求等规则；
   - 输出要求：完整可运行项目，入口为 index.html，支持单文件内联或多文件相对路径引用。

4. **[2026-04-20 09:13] AI发明家**：让 AI 画 UI 更准的方法——「最好能把 UI 元素的像素大小和坐标和 AI 说，这样画的比较准」；并提醒「你让 AI 慢慢调可能更耗时间」。

## 三、踩坑与解决方案

1. **[2026-04-16 03:35~03:53] 朱宇 → 金杰 / 钱琦**
   - 问题：「trae 生成代码错误挺多，不知道是不是我不会用」。
   - 原因/判断：红色不一定出错，可能是 eslint 校验。
   - 解法：嫌麻烦可以关闭校验（不校验）。
   - 结论：看到红色先分辨是语法错误还是 lint 提示。

2. **[2026-04-19 09:00~10:22] 李巍 / AI发明家**
   - 问题：互动空间作品被拒两次，且文中没有「游戏」字样。
   - 原因：互动空间作品「不属于『游戏』，建议不要使用『游戏』表述」；游戏需要版号/资质。李巍误以为描述里不能出现「游戏」字样。
   - 解法/结论：**是作品内部不能出现「游戏」字样，不是描述不能有**；互动空间是可互动的作品（如敲木鱼）。李巍原话：「我一直改错了地方」。

3. **[2026-04-20 09:00~09:29] 金杰 / 李巍 / AI发明家**
   - 问题：让 Godot/AI 画地形、画飞行棋棋盘都画不出来。
   - 原因：AI 读图/生图能力弱，「我图塞嘴里了它不会看」。
   - 解法：把 UI 元素的像素大小和坐标明确告诉 AI。
