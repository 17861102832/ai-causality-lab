## 三、踩坑与解决方案（问题 → 原因 → 解法 → 结论）

1. **TRAE 代码补全速度很慢** [2025-11-28] 杜昔月（官方答疑 VOL.5）
   - 问题：补全速度慢。
   - 原因/自查：插件导致 LSP 冲突。
   - 解法：先禁用所有插件，重启后确认是否恢复正常；存在部分插件会导致 LSP 冲突，如「Vue-Official 插件，建议退回 1.8.27」。
   - 结论：插件冲突优先排查。

2. **TRAE 补全消失** [2025-11-28] 杜昔月
   - 问题：补全消失。
   - 原因：网络延迟/超时，或梯子（代理）拦截。
   - 解法：先检测网络环境；若必须连梯子，可将「trae-api-sg.mchost.guru」和「trae-api-us.mchost.guru」域名纳入梯子的不转发规则。

3. **TRAE 补全出现提示音** [2025-11-28] 杜昔月
   - 原因：开启了无障碍模式（如从其他 IDE 导入配置时带入）。
   - 解法：将 Accessibility Support 配置改为 off 或 auto。

4. **cue 补全快捷键与 IDE 自带补全冲突** [2025-11-28] 杜昔月
   - 结论："这个问题较难彻底解决，可以通过不同的快捷键来规避。" 同时出现时，用「Enter 键」采纳 IDE 自带补全，用「Tab 键」采纳 cue 补全。

5. **没有 Autoimport 或 rename** [2025-11-28] 杜昔月
   - 解法：检查 LSP（语言类插件）的类型检查是否已开启。Cmd+shift+P → 输入 settings → Open User Settings → 至少开启 "basic" 及以上类型检查。验证：在类名/函数名右键「Go to References」看是否搜到项目内引用（初始化可能需一段时间）。

6. **AI 生成 Trae 项目网页刷新不出来 / 报错** [2025-12-06 / 2025-11-20] 郑铠聪 / 用户031695
   - 问题：生成的项目网页刷新不出来，命令行说没这个命令。
   - 原因：开发者服务器没启动 / 端口不对。
   - 解法：在终端启动一下，或看看端口对不对，"让 AI 帮你启动就好"；发送 `continue` 即可（针对 error 场景）。

7. **对 AI 说需求"get 不到重点"** [2025-12-06] Sky.Sea / 郑铠聪
   - 现象："说了四次了我真烦了"。

8. **AI 不围绕策划案/上下文工作** [2025-12-10] Sky.Sea / 刘金良
   - 原因："有固定大小"（上下文有限，"他对你的行业都不了解，他对你让他做的事情也不清楚"）。
   - 解法：与 AI 沟通，让它定规范/标准/流程/验收标准；做游戏难点在于"AI 不知道动态的过程，调试也很难"。
