## 三、踩坑与解决方案

### 1. 火山引擎部署自定义域名验证 DNS 失败
- 问题：复制项目设置里的域名当自定义域名，"验证 dns 失败"。
- 原因（推断）：该域名非自有域名，无法完成 DNS 验证。
- 解法：[2026-04-29 12:10] AI发明家："那可能得买个域名了"；[2026-04-29 12:10] JasonShane："618 买一下就行了""我的 188 块 10 年"。
- 结论：用平台自有域名可直接部署；自定义域名需自购并做 DNS 验证。

### 2. Antigravity 发消息无响应（被其他工具污染 Git 配置）
- 问题：发消息瞬间停止生成。
- 原因：仓库 `.git/config` 里被写入 `extensions.worktreeConfig = true`，Antigravity 内部 Go 版 Git 库不支持。
- 解法：`git config --local --unset extensions.worktreeConfig`，重启 Antigravity。
- 结论：[2026-05-08 15:44] 李巍调侃"claude 给 gemini 下毒是吧"。

### 3. TRAE 配置本地/中转模型"标记任务完成但无内容"
- 问题：自定义模型链接不报错，但每次只"标记任务完成"，无任何输出，token 也不消耗。
