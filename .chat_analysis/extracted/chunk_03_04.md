## 三、踩坑与解决方案（问题 → 原因 → 解法 → 结论）

1. **AI 直接改引擎工程文件会崩**
   - 问题：拟用 AI 操作 Cocos 项目文件。
   - 原因：`[2025-11-03 09:09] FYF`「你直接操作cocos的文件会崩的」，工程文件（.scene/.prefab）结构复杂。
   - 解法：走编辑器扩展 API，在 editor 场景下用代码生成并保存成文件（`[09:00~09:01] FYF`）。
   - 结论：不要直接改工程文件，用编辑器 API 生成。

2. **AI 不能直接创建预制体/场景节点**
