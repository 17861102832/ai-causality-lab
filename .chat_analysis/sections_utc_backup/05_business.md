# 第五部分：上架、合规与变现

把 AI 做出来的作品变成"能上架、能过审、能赚钱"的产品，靠的从来不是技术，而是对资质、平台规则、变现模式与分发的一整套认知——本部分把「TRAE 交流群｜游戏」两年来群友亲历的规则、价格、真实收益与踩坑案例，整理成独立开发者可直接照做的上架手册。

### 5.1.3 AI 辅助编程的软著新规要点

这是本部分**最需要独立开发者读懂的一条合规新规**。`[2026-04-04] 用户031695` 做过一次完整的拆解，核心五点如下：

| 维度 | 要点（原文提炼） |
|---|---|
| **适用范围** | 只针对国内"软著"申请环节（中国版权保护中心）；用 Trae/Cursor 辅助开发**完全没问题**；只有当你**强制上架国内安卓应用商店**、或**要薅补贴/学分**时才需要理会 |
| **官方目的** | 打击"纯 AI 灌水"的软著黑灰产；全球版权法底层共识是「版权只保护人类的智力成果，纯 AI 生成的内容不受版权保护」 |
| **技术现实** | 目前**没有任何查重工具能 100% 精准鉴定**业务代码是人类手敲还是 AI 补全 |
| **真正的红线** | 直接把大模型的回答**原封不动复制粘贴**；提交文档残留"好的，以下是为您生成的代码""As an AI language model..."等**穿帮字眼** |
| **结论** | 「各位不用怕，只要不是水的，就没事」 |

## 5.2 平台规则与上架要求

### 5.2.1 抖音小游戏：IAA / IAP 差异与入驻

先把两个最关键的概念钉死：

- **IAA** = In App（application）Advertisement，应用内广告变现（典型如"羊了个羊"）；**IAP** = 应用内购买（`[2025-09-25 08:25] 李佳宁`）。

| 维度 | IAA（广告） | IAP（内购） |
|---|---|---|
| 变现方式 | 看广告 | 充值/内购 |
| 版号要求 | **不需要** | **必须要** |
| 个人主体 | 可做 | **不可做**（"个人主体暂时无法创建 IAP 小游戏"） |
| 企业主体 | 可做 | 拿到版号后**可做** |
| 来源 | `[2025-10-31 08:39] 李佳宁`、`[2025-11-07 17:15-17:24]` | 同左 |

入驻与扶持要点：

- **个人身份证可直接注册**：`[2025-10-31 08:35] 李佳宁`——「抖音小游戏支持个人身份证注册」。
- **新游冷启动免费**：`[2025-09-22 11:05] 李佳宁`——「抖音小游戏变现不错，新游冷启动免费」。
- **流量扶持可观**：`[2025-11-07 07:38] 刘文溢`——「佳宁会先给咱来个单天百万级的流量扶持」。
- **个人开发者专群**：`[2025-11-07 07:36] 李佳宁` 建「抖音小游戏个人开发者群」，专为个人设立、有扶持倾向（入群链接见资源章节）。
- **引擎侧全免费**：`[2025-10-31 06:02~06:08] 李佳宁`——团结引擎个人主体的编辑器和导出**全部免费**。
- **支持的引擎矩阵**：`[2025-11-03 09:17] 李佳宁`——「我们 laya/cocos/unity/团结/Godot 都支持嘿嘿」。
- 官方资源：抖音开放平台"小游戏审核常见问题-资质篇"、开发者入驻文档、小游戏学堂课程（链接见资源章节）。

### 5.2.2 抖音「互动空间」：硬约束清单

抖音「互动空间」是群内 2026 年上半年的热点形态——上传一个纯静态 HTML 代码包，用抖音扫码即可玩。它的规则**极其严格且具体**，以下是官方内测规则的完整整理。

**内测硬性规则**（`[2026-04-16 11:32~11:34] 李佳宁` + `[2026-04-17 08:48] 耿家威`）：

| 类别 | 硬约束 |
|---|---|
| **包体** | ZIP 包**限制 8M 以内**；产物为 **HTML 代码包**（纯静态资源）；测好后会放开限制 |
| **作品数量** | 单账号最多创建 **5 个作品**；已创建作品**不可删除**，仅可修改更新 |
| **访问人数** | 发布后的作品最多支持 **100 人访问**，超出后新用户无法访问 |
| **审核周期** | **1 个工作日**，通过后抖音站内信通知（另一说法：`[2026-04-29 09:59] 李佳宁`「日清的，2-4 小时」） |
| **体验版本** | 需抖音 **3.8.20 及以上版本**扫码体验；未发布作品仅本人可访问 |
| **网络** | **完全离线运行**；禁止任何网络请求 API（`fetch` / `XMLHttpRequest` / `WebSocket`）；禁止外部 CDN 与外部跳转链接 |
| **体积** | 强制 **< 8MB** |
| **适配** | 需移动端响应式自适应（`rem` / `vw` / `vh`，**禁止横向滚动条**） |
| **持久化** | **仅可用 `localStorage`** |
| **健壮性** | 需 `try-catch` 友好报错 |
| **内容** | 不得违法 / IP 侵权 / 不利于未成年人 |

**格式与形态红线**：

- **作品不属于"游戏"**：`[2026-04-20 07:04] 何国全 / [2026-04-19 05:20] 李巍`——「互动空间作品不属于『游戏』，建议不要使用『游戏』表述」。
- 这一点是典型踩坑：李巍的作品被拒两次，一度误以为**描述里**不能出现"游戏"字样，实际是**作品内部不能出现"游戏"字样，不是描述不能有**（`[2026-04-19 09:00~10:22] 李巍 / AI发明家`）。李巍原话：「我一直改错了地方」。

**其他实测限制与坑**：

- **不支持 WebSocket**：`[2026-04-27 02:45] 李巍`（李健询问打包为纯静态 zip 是否可行时得到确认）。
- **不支持长按保存/生成图片**：`[2026-04-27 06:32] 李佳宁`。
- **8M 上限长期不变**：`[2026-05-19 03:57-03:58]` 互动空间上传限制 8M，「一直都是 8」；`[03:59] 李佳宁` 解释——「800M 得加载到猴年马月，估计到几十兆之后就会考虑上技术提升加载速度」。
- **体积受限的删减实例**：`[2026-04-20 07:41] FYF` 用互动空间做贪吃蛇「跑起来效果还不错」，但「我加了声音，就 3m 去掉了」——**为控体积被迫删掉音效**。
- **加白门槛**：`[2026-04-17 11:03~11:38] 耿家威 / 李佳宁`——进入 `vcreate.douyin.com/console/interaction` 显示 404，原因是账号未"加白"，且加白系统 **19:00 下班**；解法是先填问卷申请加白，通过后刷新，或到创作者反馈群让产研排查。`[2026-04-21 12:05] AI发明家` 补充：加白审核通过后，可能要「到明天才能用」。
- **审核排队实况**：`[2026-05-10 07:44] AAG`——「抖音互动空间申请没音了，我小游戏都做出来了」；`[2026-05-05 03:50]` 多方反映"还没审核/还没给我开"，`[2026-05-05 03:11] 李佳宁` 要 uid 排查；`[2026-05-09 06:48] 李佳宁` 回复「大家前一阵子提交的作品正在内部评审中，就等出结果了」。
- **更新不实时**：`[2026-04-19 14:56 / 2026-04-20 07:49] 李巍`——游戏更新了，玩家那边还是旧版本，李佳宁表示当下也「没啥解法」。

**生态与前景**：

- **一键上传在规划中**：`[2026-04-17 11:40] 李佳宁`——**预计 5 月下旬**打通 TRAE 与抖音互动空间「一键上传」（类似现在的 GitHub）。

**阶段一：选题前（决定能不能上架）**

- [ ] 明确主体：**个人**（只能做 IAA / 广告）还是**企业**（可做 IAP，但需营业执照；代办注册几百上千元，上海部分区域可远程 + 提供注册地）。
- [ ] 明确平台：抖音小游戏 / 微信小游戏 / 互动空间 / Steam / TapTap 等 / 海外 H5，各自规则不同（见 5.2）。
- [ ] 明确变现方式：IAA（不需版号）还是 IAP（必须版号，企业主体）。
- [ ] 若做互动空间：确认作品**不属于"游戏"**，作品内部**不出现"游戏"字样**，且**完全离线**。

**阶段二：开发中（顺手满足上架技术约束）**

- [ ] 互动空间：ZIP **< 8M**、纯静态 HTML 包、**无任何网络请求 API**、无外部 CDN/跳转、`localStorage` 持久化、`rem/vw/vh` 响应式且无横向滚动条、`try-catch` 友好报错、**不支持 WebSocket / 长按保存**。
- [ ] 联网游戏：计算尽量放**服务端**，客户端只发操作不发数据（防作弊）。
- [ ] 单机游戏：确认"不需要域名、不需要资质"的边界（国内平台仍需国内服务器）。
- [ ] 体积预判：对照目标平台上限（Vercel > 20M 会卡、互动空间 8M、4399 可 2G、火山 IGA Pages 1G）。

**阶段三：上架前的资质准备**

- [ ] 申请**软著**（代办约 99 元、周期 30-45 工作日；微信可由平台代办，抖音需自办）。
- [ ] 软著申请文档**不要写得太 AI**，绝不能残留大模型穿帮字眼。
- [ ] 抖音小游戏补 **ICP 备案**；含充值游戏补**版号**（建议先注册公司）。
- [ ] 完成平台认证：微信小程序个人 30 元 / 企业 300 元；抖音小程序约 300 元。
- [ ] 涉及商标/Logo：先用 **™**（"当作商标使用"），**等注册下来再用 ®**；设计图先排查侵权风险。
- [ ] 内容自检：无违法 / 无 IP 侵权 / 不不利于未成年人。

**阶段四：上架提交与审核**

- [ ] 互动空间需先申请**加白**（入口 404 即未加白；加白系统 **19:00 下班**），审核约 **1 个工作日**（一说 2-4 小时）。
- [ ] 抖音小游戏注意名称/ID/备案**查重（先到先得）**。
- [ ] iOS 上架**坚决关闭热更新、走发版**，不要反复挑战苹果审核；儿童品类尤其严格。
- [ ] 微信侧预留充足审核周期（可能**半个月以上**）。

**阶段五：上架后运营与变现**

- [ ] 先接**激励视频广告**（个人唯一合规路径；单价约 1 次 1 分钱，靠跑量积累）。
- [ ] 争取平台**新游冷启动免费名额**与**流量扶持**（可争取单天百万级）。
- [ ] 做分发：短视频导流、up 主评论区留言、建抖音粉丝群挂主页、参与社区分享、做促活分享设计。
- [ ] 记住心法：**distribution > product**，选对用户群体，跑量优先于闭门做精品。
- [ ] 用**多平台跑量**摊薄风险（一平台 1 款 1 天几美分，需要高产）。
- [ ] 服务器做好备份与防护（git 双推、WAF），预期"营收过万"后才可能被盯上。
